# Lista de Compras / Shopping List
A bilingual (Spanish/French) shopping list web app designed for quick, mobile-friendly use.
## Live App
**https://9gcorrales.github.io/shopping-list/**
## Features
- **Bilingual items**: Each item displays in Spanish and French
- **Quick checkboxes**: Tap to select items you need
- **Adjustable quantities**: Change amounts for each item
- **Add custom items**: Type any item at the bottom, it saves to "Otros"
- **Generate list**: Creates a clean text list of checked items
- **Copy to clipboard**: One tap to copy, then paste into WhatsApp
- **Reset**: Uncheck all items to start fresh
- **Auto-save**: Your selections persist between sessions
## How to Use
1. Check the items you need
2. Adjust quantities if needed
3. Add any extra items using the input at the bottom
4. Tap **Generate List**
5. Tap **Copy to Clipboard**
6. Open WhatsApp and paste the list
## Add to Home Screen
### iPhone
1. Open the link in Safari
2. Tap the Share button
3. Tap "Add to Home Screen"
### Android
1. Open the link in Chrome
2. Tap the three-dot menu
3. Tap "Add to Home screen"
